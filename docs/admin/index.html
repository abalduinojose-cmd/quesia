Como publicar as mudanças

  1. Clique em Publicar grade: baixa o arquivo grade.json.
  2. Abra o repositório no GitHub, entre na pasta docs e envie o arquivo por cima do antigo.
  3. Em 2 a 3 minutos o site já mostra os horários novos.

Enquanto não publicar, as mudanças ficam salvas só neste aparelho.
